## Architecture de reproduction fidèle (NOUVEAU)
Le contenu de chaque sous-page est **importé verbatim** depuis l'ancien site vers la table **`site_pages`** et rendu dans notre chrome, **éditable depuis l'admin** (« Gestion du Site » → « Contenus des pages »).
- Importateur : `v2/tools/import_pages.php` (CLI). Récupère `#main-content`, **conserve le texte et la structure `.v3box` d'origine**, retire le fil d'Ariane d'origine (on affiche le nôtre).
- **Images** : template mangetoica → téléchargées dans `web-gallery/v2/pages_img/` (aucune dépendance externe) ; `c_images` → fichier local si présent ; **avatars/personnages Habbo (liens morts) → NON recréés**, remplacés par un marqueur « image d'origine indisponible » + consignés dans `missing_note`.
- **Liens** : internes `.php` et `habbo.fr/home/X` → routes locales ; externes conservés.
- CSS `.v3box` d'origine extrait et intégré (`layout.php`), sprites `boxes-v3` téléchargés localement.
- **Contenu d'archive** : les pages décrivant une offre/événement d'époque portent `is_historical=1` → bandeau « Contenu d'archive » (texte conservé **à l'identique**, non présenté comme actif).
